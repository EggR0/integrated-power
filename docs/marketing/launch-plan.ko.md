# Integrated Power 공급·홍보 실행안

기준 릴리스: `0.7.14`  
주 대상: Antigravity IDE를 Windows 11에서 사용하며, AI 사용량·로컬 GPU·여러 실행 경로를 함께 관리해야 하는 개발자

## 1. 한 문장 포지셔닝

Integrated Power는 단순 quota 표시기가 아니라, Antigravity·Codex·로컬 LLM·GPU 상태를 한 화면에서 확인하고 작업 실행 경로를 이어 주는 Windows용 AI 작업 컨트롤 센터다.

## 3. 30일 실행 순서

### 1주차: 설치 가능한 증거 만들기

- 30초 화면 녹화 1개: `Dashboard → quota 부족 → GPU/로컬 LLM 확인 → 실행 경로 선택`.
- 기능을 세 장면으로 나눈 스크린샷 3개: Dashboard, Configuration Center, 실행 경로/로컬 상태.
- README 첫 화면에 설치 명령, 개인정보 경계, “quota-only 확장과 다른 점”을 배치한다.
- VSIX 직접 설치 경로를 최신 릴리스 기준으로 점검한다.

### 2주차: 문제 중심 공개

- Reddit에는 제품 출시가 아니라 “Antigravity에서 quota가 부족할 때 작업을 멈추지 않는 방법”으로 게시한다.
- Google AI Developers Forum에는 로컬 처리·토큰 경계·실행 경로 선택을 기술적으로 설명한다.
- 같은 주제의 Dev.to/GeekNews 글은 영상과 설치 안내를 연결한다.

### 3주차: 제3자 유통

- Antigravity·Ollama·Codex를 다루는 소형 채널 10곳에 동일한 데모 패키지를 보낸다.
- 요청은 리뷰가 아니라 “5분 사용 후 문제점 3개만 알려 달라”로 낮춘다.
- 반응이 있는 채널의 질문을 FAQ와 다음 릴리스 노트에 반영한다.

### 4주차: 유지·추천 루프

- 새 릴리스마다 “무엇이 바뀌었고 누구에게 유용한가”를 한 문단으로 게시한다.
- 사용자가 직접 공유할 수 있는 설치 한 줄과 짧은 설명을 제공한다.
- 다운로드 수만 보지 말고 설치 성공, 7일 재사용, 이슈·기능 요청을 기록한다.

## 4. 메시지 원칙

- `quota를 늘린다`고 말하지 않는다. 사용량을 관측하거나 다른 실행 경로로 전환하는 도구라고 말한다.
- Antigravity quota와 직접 측정한 Claude/API/CLI 사용량을 섞지 않는다.
- 로컬 처리·외부 통신·저장 데이터 범위를 구체적으로 공개한다.
- 경쟁 확장을 공격하지 말고 Integrated Power의 동작을 검증 가능하게 보여 준다.
- “모든 VS Code 파생 IDE 지원”이라고 확대하지 않는다. 우선 지원 범위는 Antigravity IDE on Windows 11이다.

## 5. 주간 측정표

| 단계 | 기록할 지표 | 판단 기준 |
|---|---|---|
| 노출 | 게시물 조회, 영상 조회 | 어떤 문제 제목이 반응을 얻는가 |
| 관심 | 링크 클릭, README 체류, 질문 수 | 설명이 설치 전 불안을 해소하는가 |
| 설치 | VSIX 설치 문의·성공 보고 | 공급 경로가 막히지 않는가 |
| 활성 | 첫 실행, Dashboard 열기, 경로 선택 | 실제 가치가 전달되는가 |
| 유지 | 7일 재사용, 업데이트 설치, 이슈 | 일회성 다운로드가 아닌가 |

## 6. 실행 완료 조건

- 게시물 3개와 영상 1개가 실제 복사 가능한 상태다.
- 모든 게시물은 최신 릴리스 설치 경로 하나만 가리킨다.
- 기능 설명과 보안·데이터 경계가 README 및 지원 문서와 일치한다.
- 외부 게시 전에는 각 커뮤니티 규칙과 링크 상태를 사람이 최종 확인한다.
