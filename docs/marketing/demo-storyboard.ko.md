# 30초 데모 스토리보드

목표는 기능 목록을 읽히는 것이 아니라 “작업이 막혔을 때 다음 경로로 이어진다”는 흐름을 한 번에 보여 주는 것이다.

| 시간 | 화면 | 자막/내레이션 |
|---:|---|---|
| 0–4초 | Antigravity IDE에서 Dashboard 열기 | “AI 작업 상태와 사용량을 한 화면에서 확인합니다.” |
| 4–9초 | Antigravity 사용량 카드와 reset 상태 | “quota 숫자와 제공자 상태를 구분해서 봅니다.” |
| 9–14초 | GPU·VRAM·로컬 LLM 상태 카드 | “로컬 컴퓨팅 경로가 준비됐는지도 바로 확인합니다.” |
| 14–21초 | Configuration Center에서 실행 경로 확인 | “작업을 직접 처리할지, Codex나 로컬 LLM으로 넘길지 선택합니다.” |
| 21–26초 | 작업 실행 기록과 결과 아티팩트 열기 | “선택 이유와 다음 작업을 잃지 않도록 기록합니다.” |
| 26–30초 | 제품명·설치 방법·Windows 11 표시 | “Integrated Power — Antigravity용 Windows 11 작업 컨트롤 센터.” |

## 촬영 규칙

- 실제 계정 토큰, 프로젝트 경로, 프롬프트 원문은 화면에 노출하지 않는다.
- 로딩이 길면 녹화를 이어 붙이지 말고 상태 변화가 보이는 짧은 장면만 사용한다.
- quota를 “남은 API 잔액”이나 “제한 해제”로 표현하지 않는다.
- 마지막 프레임에는 `Integrated Power`, `Publisher EggR`, 설치 경로를 2초 이상 표시한다.

## 설명란 템플릿

Integrated Power는 Antigravity·Codex·로컬 LLM·GPU 상태를 한 화면에서 확인하고 작업 실행 경로를 이어 주는 Windows 11 확장입니다.
