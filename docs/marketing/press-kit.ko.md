# Integrated Power 공유용 프레스 키트

## 제품명

Integrated Power

## 짧은 설명

Antigravity IDE에서 AI 사용량, GPU·로컬 LLM 상태, Codex 실행 경로를 한 화면에서 확인하고 작업을 이어 가는 Windows 11 확장입니다.

## 15자 설명

AI 작업 경로 컨트롤 센터

## 50자 설명

Antigravity quota·GPU·로컬 LLM·Codex 상태를 한 화면에서 관리합니다.

## 150자 설명

Integrated Power는 Antigravity IDE용 Windows 11 확장입니다. quota를 우회하지 않고, 제공자 사용량·GPU·로컬 LLM·Codex 경로를 구분해 보여 주며 작업을 다음 실행 경로로 이어 줍니다.

## 차별점

- quota 숫자만 보여 주지 않고 작업 실행 경로까지 연결한다.
- Antigravity quota, 직접 측정한 Claude/API/CLI 활동, 로컬 GPU 상태를 섞지 않는다.
- Dashboard·Integrated Orchestrator·Private Git Knowledge를 독립 구성으로 다룬다.
- 계정 로그인이나 외부 서버 전송을 제품 가치의 전제로 삼지 않는다.

## 대상 사용자

- Antigravity IDE를 매일 사용하는 Windows 11 개발자
- AI quota가 부족할 때 Codex나 로컬 LLM으로 작업을 이어 가야 하는 사용자
- Ollama/vLLM과 GPU 상태를 작업 흐름 안에서 확인하려는 사용자
- 여러 에이전트의 실행 기록과 다음 작업을 잃고 싶지 않은 사용자
